# OA 系统 前后端接口文档

> 服务地址：`http://localhost:8080` ｜ Swagger UI：`/swagger-ui.html` ｜ OpenAPI：`/v3/api-docs`
> 认证：除标注「公开」外，均需请求头 `Authorization: Bearer <token>`。
> 统一返回：`{ code, message, data }`；分页 data 为 `PageResult { total, records, pageNum, pageSize }`。

---

## 0. 通用约定

### 0.1 鉴权方式
所有受保护接口请求头携带：
```
Authorization: Bearer eyJhbGciOi...
```

### 0.2 错误响应
| code | HTTP | message 示例 |
|---|---|---|
| 200 | 200 | success |
| 400 | 400 | 用户名已存在 / 非法状态流转: ... / 参数校验: 字段: ... |
| 401 | 401 | 未认证或登录已过期 / 用户名或密码错误 |
| 403 | 403 | 无访问权限 / 只有指定审批人可以审批该申请单 / 仅上传者或管理员可删除该文件 |
| 404 | 404 | 资源不存在 / 请假申请不存在: id=... |
| 500 | 500 | 系统内部错误 |

### 0.3 枚举字典
**审批状态（status）**：`0` 草稿、`1` 待审批、`2` 通过、`3` 拒绝、`4` 撤回（VO 中同时返回 `statusDesc`）。
**审批动作（action）**：`1` 提交、`2` 通过、`3` 拒绝、`4` 撤回（VO 中同时返回 `actionDesc`）。
**业务类型（businessType）**：`1` 请假、`2` 报销。
**请假类型（leaveType）**：`1` 年假、`2` 事假、`3` 病假。
**菜单类型（type）**：`1` 目录、`2` 菜单、`3` 按钮。
**用户/角色/菜单状态（status）**：`1` 启用、`0` 禁用。
**通知已读（readFlag）**：`0` 未读、`1` 已读。

## 一、认证模块 `/api/auth`

### 1. 注册
- **请求方式**：`POST` ｜ **路径**：`/api/auth/register` ｜ **权限**：公开 ｜ **模块**：认证

请求参数（JSON）：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 登录名，3-20 位，仅字母/数字/下划线 |
| password | string | 是 | 密码 8-20 位，须同时含字母和数字 |
| nickname | string | 否 | 昵称，≤50 |
| email | string | 否 | 邮箱格式校验 |
| phone | string | 否 | 手机号格式校验 |

请求示例：
```json
{ "username": "zhangsan", "password": "Passw0rd123", "nickname": "张三" }
```
响应示例：
```json
{ "code": 200, "message": "success",
  "data": { "id": 2, "username": "zhangsan", "nickname": "张三", "email": null,
            "phone": null, "avatar": null, "status": 1,
            "createTime": "2026-08-03 10:00:00", "updateTime": "2026-08-03 10:00:00" } }
```
⚠️ 注册用户无默认角色（需管理员分配）；用户名重复返回 400。

---

### 2. 登录
- **请求方式**：`POST` ｜ **路径**：`/api/auth/login` ｜ **权限**：公开 ｜ **模块**：认证

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 登录名 |
| password | string | 是 | 密码 |

请求示例：
```json
{ "username": "admin", "password": "Admin@123456" }
```
响应示例：
```json
{ "code": 200, "message": "success",
  "data": {
    "token": "eyJhbGciOi...", "tokenType": "Bearer", "expiresIn": 2592000,
    "user": { "id": 1, "username": "admin", "nickname": "系统管理员", "status": 1 } } }
```
说明：账号禁用返回 403；用户名或密码错误返回 401（不区分，防枚举）。

---

### 3. 当前用户信息
- **请求方式**：`GET` ｜ **路径**：`/api/auth/me` ｜ **权限**：登录 ｜ **模块**：认证

响应示例：
```json
{ "code": 200, "message": "success",
  "data": {
    "user": { "id": 1, "username": "admin", "nickname": "系统管理员", "status": 1 },
    "roles": ["admin"],
    "permissions": ["system:user:list", "system:user:add", "system:user:edit",
                    "system:user:remove", "system:role:list", "system:role:add",
                    "system:role:edit", "system:role:remove", "system:role:assign",
                    "system:menu:list", "system:menu:add", "system:menu:edit", "system:menu:remove"] } }
```
用途：前端登录后拉取角色与权限，用于路由过滤与按钮级权限。

---

### 4. 登出
- **请求方式**：`POST` ｜ **路径**：`/api/auth/logout` ｜ **权限**：登录 ｜ **模块**：认证
- 无请求体，从 `Authorization` 头取 token 删除登录态缓存，token 立即失效。
- 响应：`{ "code": 200, "message": "success", "data": null }`

## 二、用户管理 `/api/users`

> 需 `system:user:*` 权限。

### 5. 用户分页查询
- **请求方式**：`GET` ｜ **路径**：`/api/users` ｜ **权限**：`system:user:list` ｜ **模块**：用户管理

查询参数（Query）：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | number | 否 | 页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 10，上限 100 |
| username | string | 否 | 用户名模糊匹配 |
| status | number | 否 | 1 启用 / 0 禁用 |

请求示例：`GET /api/users?username=ad&status=1&pageNum=1&pageSize=10`
响应示例：
```json
{ "code": 200, "message": "success",
  "data": { "total": 1, "pageNum": 1, "pageSize": 10,
    "records": [ { "id": 1, "username": "admin", "nickname": "系统管理员",
                   "email": "admin@oa.local", "phone": null, "avatar": null,
                   "status": 1, "createTime": "...", "updateTime": "..." } ] } }
```

### 6. 用户详情
- **请求方式**：`GET` ｜ **路径**：`/api/users/{id}` ｜ **权限**：`system:user:list` ｜ **模块**：用户管理
- 返回单个 `UserVO`（同上 records 内字段）。不存在返回 404。

### 7. 修改用户
- **请求方式**：`PUT` ｜ **路径**：`/api/users/{id}` ｜ **权限**：`system:user:edit` ｜ **模块**：用户管理

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| nickname | string | 否 | ≤50 |
| email | string | 否 | 邮箱格式 |
| phone | string | 否 | 手机号格式 |
| avatar | string | 否 | 头像 URL，≤255 |
| status | number | 否 | 0/1 |

请求示例：
```json
{ "nickname": "新昵称", "email": "a@b.com", "phone": "13800138000", "avatar": "", "status": 1 }
```
响应：修改后的 `UserVO`。

### 8. 删除用户
- **请求方式**：`DELETE` ｜ **路径**：`/api/users/{id}` ｜ **权限**：`system:user:remove` ｜ **模块**：用户管理
- 逻辑删除 + 清理用户-角色关联。响应：`{ code:200, message:"success", data:null }`

### 9. 给用户分配角色
- **请求方式**：`PUT` ｜ **路径**：`/api/users/{id}/roles` ｜ **权限**：`system:user:edit` ｜ **模块**：用户管理
- 全量替换该用户角色。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| roleIds | number[] | 是 | 角色 ID 数组 |

请求示例：`{ "roleIds": [1, 2] }` → 响应 `{ code:200, message:"success", data:null }`

### 10. 用户当前角色 ID 列表
- **请求方式**：`GET` ｜ **路径**：`/api/users/{id}/roles` ｜ **权限**：`system:user:list` ｜ **模块**：用户管理
- 用于「分配角色」弹窗回显。
- 响应：`{ code:200, data: [1, 2] }`

## 三、角色管理 `/api/roles`

> 需 `system:role:*` 权限。

### 11. 角色分页查询
- **请求方式**：`GET` ｜ **路径**：`/api/roles` ｜ **权限**：`system:role:list` ｜ **模块**：角色管理

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | number | 否 | 默认 1 |
| pageSize | number | 否 | 默认 10，上限 100 |
| name | string | 否 | 角色名称模糊 |
| status | number | 否 | 0/1 |

请求示例：`GET /api/roles?name=&status=1&pageNum=1&pageSize=10`
响应 data：`{ total, records: [RoleVO] }`，RoleVO 字段：`id / name / code / description / status / createTime / updateTime`。

### 12. 全部启用角色
- **请求方式**：`GET` ｜ **路径**：`/api/roles/all` ｜ **权限**：`system:role:list` ｜ **模块**：角色管理
- 返回全部启用角色的数组（用于分配角色下拉）。
- 响应：`{ code:200, data: [ { id:1, name:"系统管理员", code:"admin", ... } ] }`

### 13. 角色详情
- **请求方式**：`GET` ｜ **路径**：`/api/roles/{id}` ｜ **权限**：`system:role:list` ｜ **模块**：角色管理
- 返回单个 `RoleVO`。

### 14. 新增角色
- **请求方式**：`POST` ｜ **路径**：`/api/roles` ｜ **权限**：`system:role:add` ｜ **模块**：角色管理

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | ≤50 |
| code | string | 是 | 字母开头，仅字母/数字/下划线，≤50，全局唯一 |
| description | string | 否 | ≤255 |
| status | number | 否 | 默认 1 |

请求示例：
```json
{ "name": "部门主管", "code": "manager", "description": "负责部门审批", "status": 1 }
```
响应：新建的 `RoleVO`。code 重复返回 400。

### 15. 修改角色
- **请求方式**：`PUT` ｜ **路径**：`/api/roles/{id}` ｜ **权限**：`system:role:edit` ｜ **模块**：角色管理
- 参数同新增。响应：修改后 `RoleVO`。

### 16. 删除角色
- **请求方式**：`DELETE` ｜ **路径**：`/api/roles/{id}` ｜ **权限**：`system:role:remove` ｜ **模块**：角色管理
- 逻辑删除 + 清理角色-用户/角色-菜单关联。

### 17. 给角色分配菜单
- **请求方式**：`PUT` ｜ **路径**：`/api/roles/{id}/menus` ｜ **权限**：`system:role:assign` ｜ **模块**：角色管理
- 全量替换角色菜单。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| menuIds | number[] | 是 | 菜单 ID 数组（含目录/菜单/按钮） |

请求示例：`{ "menuIds": [100, 200, 201, 202, 203, 204] }` → `{ code:200, data:null }`

### 18. 角色当前菜单 ID 列表
- **请求方式**：`GET` ｜ **路径**：`/api/roles/{id}/menus` ｜ **权限**：`system:role:assign` ｜ **模块**：角色管理
- 用于「分配菜单」树勾选回显。响应：`{ code:200, data: [100, 200, 201, ...] }`

## 四、菜单管理 `/api/menus`

> 需 `system:menu:*` 权限。

### 19. 菜单树
- **请求方式**：`GET` ｜ **路径**：`/api/menus/tree` ｜ **权限**：`system:menu:list` ｜ **模块**：菜单管理
- 返回全部启用菜单的树形结构（含 children）。

### 20. 菜单详情
- **请求方式**：`GET` ｜ **路径**：`/api/menus/{id}` ｜ **权限**：`system:menu:list` ｜ **模块**：菜单管理

### 21. 新增菜单
- **请求方式**：`POST` ｜ **路径**：`/api/menus` ｜ **权限**：`system:menu:add` ｜ **模块**：菜单管理

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| parentId | number | 是 | 父菜单 ID，0 为根 |
| name | string | 是 | ≤50 |
| path | string | 否 | 路由地址，≤255 |
| component | string | 否 | 组件路径，≤255 |
| icon | string | 否 | ≤50 |
| type | number | 是 | 1 目录 / 2 菜单 / 3 按钮 |

请求示例：
```json
{ "parentId": 200, "name": "用户重置密码", "type": 3, "perms": "system:user:reset", "sort": 5, "status": 1 }
```

### 22. 修改菜单

- 参数同新增。父菜单不能为自身。

### 23. 删除菜单
- **请求方式**：`DELETE` ｜ **路径**：`/api/menus/{id}` ｜ **权限**：`system:menu:remove` ｜ **模块**：菜单管理
- 存在子菜单时拒绝删除（400）；清理角色-菜单关联。

## 五、请假审批 `/api/approvals/leave`

> 登录即可。状态机非法流转返回 400；非审批人操作返回 403。

### 24. 提交请假申请
- **请求方式**：`POST` ｜ **路径**：`/api/approvals/leave` ｜ **权限**：登录 ｜ **模块**：请假审批

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| leaveType | number | 是 | 1 年假 / 2 事假 / 3 病假 |
| startDate | string | 是 | `yyyy-MM-dd`，不晚于 endDate |
| endDate | string | 是 | `yyyy-MM-dd` |
| days | number | 是 | ≥1 |
| reason | string | 是 | ≤500 |
| approverId | number | 是 | 审批人用户 ID（须为启用用户） |

请求示例：
```json
{ "leaveType": 2, "startDate": "2026-08-10", "endDate": "2026-08-12", "days": 3,
  "reason": "家中有事", "approverId": 1 }
```
响应 data（LeaveVO）：
```json
{ "id": 1, "userId": 2, "applicantName": "张三", "leaveType": 2,
  "startDate": "2026-08-10", "endDate": "2026-08-12", "days": 3, "reason": "家中有事",
  "status": 1, "statusDesc": "待审批", "approverId": 1, "approverName": "系统管理员",
  "createTime": "...", "updateTime": "..." }
```

### 25. 我的请假申请
- **请求方式**：`GET` ｜ **路径**：`/api/approvals/leave/my` ｜ **权限**：登录 ｜ **模块**：请假审批

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | number | 否 | 默认 1 |
| pageSize | number | 否 | 默认 10，上限 100 |
| status | number | 否 | 0/1/2/3/4 状态筛选 |

请求示例：`GET /api/approvals/leave/my?status=1&pageNum=1&pageSize=10`
响应 data：`{ total, records: [LeaveVO] }`。

### 26. 待我审批列表
- **请求方式**：`GET` ｜ **路径**：`/api/approvals/leave/pending` ｜ **权限**：登录 ｜ **模块**：请假审批
- 当前登录用户为审批人的待审批申请（status 强制 = 1）。参数同上（status 忽略）。

### 27. 请假申请详情
- **请求方式**：`GET` ｜ **路径**：`/api/approvals/leave/{id}` ｜ **权限**：登录（申请人/审批人） ｜ **模块**：请假审批
- 返回单个 `LeaveVO`；非申请人/审批人返回 403。

### 28. 审批通过
- **请求方式**：`PUT` ｜ **路径**：`/api/approvals/leave/{id}/approve` ｜ **权限**：登录（指定审批人） ｜ **模块**：请假审批

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| comment | string | 否 | 审批意见，≤500（请求体可为空对象 `{}`） |

请求示例：`{ "comment": "同意" }` → 响应 `{ code:200, data:null }`

### 29. 审批拒绝
- **请求方式**：`PUT` ｜ **路径**：`/api/approvals/leave/{id}/reject` ｜ **权限**：登录（指定审批人） ｜ **模块**：请假审批
- 参数同通过。建议拒绝时填写意见。

### 30. 撤回申请
- **请求方式**：`PUT` ｜ **路径**：`/api/approvals/leave/{id}/cancel` ｜ **权限**：登录（仅申请人本人） ｜ **模块**：请假审批
- 无请求体。仅 DRAFT/PENDING 可撤回，否则 400。

## 八、文件管理 `/api/files`

### 39. 上传文件
- **请求方式**：`POST` ｜ **路径**：`/api/files/upload` ｜ **权限**：登录 ｜ **模块**：文件管理
- 请求类型：`multipart/form-data`，字段名 `file`；大小 ≤10MB；扩展名白名单：`jpg,jpeg,png,gif,pdf,doc,docx,xls,xlsx,txt,csv`。
- 响应 data（FileVO）：`id / originalName / size / contentType / url / uploaderId / uploaderName / createTime`。
```
{ "code": 200, "message": "success",
  "data": { "id": 1, "originalName": "report.pdf", "size": 10240,
            "contentType": "application/pdf", "url": "/api/files/1/download",
            "uploaderId": 1, "uploaderName": "系统管理员", "createTime": "..." } }
```

### 40. 下载文件
- **请求方式**：`GET` ｜ **路径**：`/api/files/{id}/download` ｜ **权限**：登录 ｜ **模块**：文件管理
- 返回**二进制流**（`Content-Disposition: attachment`，原始文件名），非 JSON。
- 前端须用 axios `responseType: 'blob'` 携带 token 下载。

### 41. 文件分页列表
- **请求方式**：`GET` ｜ **路径**：`/api/files` ｜ **权限**：登录 ｜ **模块**：文件管理

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNum | number | 否 | 默认 1 |
| pageSize | number | 否 | 默认 10，上限 100 |
| name | string | 否 | 原始文件名模糊 |
| contentType | string | 否 | MIME 类型模糊 |

响应 data：`{ total, records: [FileVO] }`。

### 42. 删除文件
- **请求方式**：`DELETE` ｜ **路径**：`/api/files/{id}` ｜ **权限**：登录（上传者或 admin） ｜ **模块**：文件管理
- 逻辑删除 + 物理文件清理；非上传者且非 admin 返回 403。

### 43. 我的通知分页
- **请求方式**：`GET` ｜ **路径**：`/api/messages` ｜ **权限**：登录 ｜ **模块**：系统通知

## 十、缓存管理 `/api/cache`

### 47. 清除缓存
- **请求方式**：`POST` ｜ **路径**：`/api/cache/evict` ｜ **权限**：登录（运维接口，任何登录用户可调，**前端勿对普通用户开放**） ｜ **模块**：缓存管理

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| key | string | 是 | 缓存 key；含 `*` 时按模式清除（如 `oa:user:info:*`） |

请求示例：
```json
{ "key": "oa:menu:tree" }
```
响应：`{ code:200, data:null }`。
常用 key：`oa:auth:token:{token}`、`oa:user:info:{userId}`、`oa:user:detail:{userId}`、`oa:menu:tree`。
